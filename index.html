Bàn phím & gõ tắt

Text replacement

Gõ chuỗi tắt rồi nhấn Space, Enter hoặc dấu câu. Nội dung thay thế có thể có nhiều dòng. Chuỗi có tiền tố như “;sig” giúp tránh đụng từ thông thường.

Chuỗi tắtThay bằng

JSON chứa cấu hình và gõ tắt, không chứa tài liệu. Import thay toàn bộ cấu hình sau khi bạn nhấn Lưu.

Gõ tiếng Việt, offline

Chọn bàn phím English / ABC của hệ điều hành, rồi bật Tiếng Việt ở đây. Tránh bật hai bộ gõ Telex cùng lúc. Trên điện thoại, tắt autocorrect của bàn phím nếu nó tự sửa các chuỗi Telex.

Hỗ trợ dấu ở cuối từ, tự chuyển vị trí dấu khi thêm chữ, chữ hoa và Unicode NFC. Bàn phím gom chữ qua composition sẽ chuyển Telex khi chốt từ; composition có dấu tiếng Việt được giữ nguyên. Đây là Telex cơ bản; không có bộ kiểm tra chính tả hoặc tự đoán tiếng Anh. Không dùng phím “[”, “]” hay “w” đơn lẻ để tạo nguyên âm, để giữ cú pháp Markdown.

Markdown là editor mã nguồn với preview: tiêu đề, đậm/nghiêng, danh sách, checklist, trích dẫn, code, link và bảng cơ bản. Không phải editor WYSIWYG. HTML trong tài liệu hiển thị như văn bản; hình ảnh không tải từ mạng. Paste và import giữ nguyên, không chạy lại Telex.

Mở file

macOS / Windows / Linux: tải go-viet.html rồi mở bằng Safari, Chrome, Firefox hoặc Edge. Không cần cài package, server hay kết nối mạng.

iPhone / iPad: Files / Quick Look có thể chỉ xem trước HTML, không chạy ứng dụng. Cần app mở HTML có hỗ trợ JavaScript / WebView, hoặc phục vụ file qua một địa chỉ HTTP rồi mở trong Safari. File tự nó không cài thành PWA. Bố cục và bộ gõ hỗ trợ màn hình cảm ứng, nhưng chưa kiểm thử trên thiết bị iOS thực.

Lưu nháp & riêng tư

Không gửi nội dung qua mạng. Nháp và cấu hình dùng localStorage của trình duyệt khi khả dụng; không ghi ngược vào file HTML. Chế độ riêng tư, đổi trình duyệt, đổi vị trí file hoặc xoá dữ liệu có thể làm mất nháp. Tải .md / .txt và export JSON để có bản sao bền vững. Không có đồng bộ giữa máy.

Giới hạn: tài liệu mở tối đa 2 MiB; cấu hình 1 MiB / 500 gõ tắt. Undo giữ tối đa 300 thao tác / khoảng 4 MiB dữ liệu thay đổi, chỉ trong phiên đang mở.
